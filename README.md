# Sophie & Aiden's Pokémon channel: editing toolkit

Our house editing style and the scripts that make it. Start with [CLAUDE.md](CLAUDE.md).

- `editor/`: prep (download, transcribe), build_main (main video), build_shorts (2 Shorts), graphics, sounds, subtitles
- `projects/<video>/project.py`: the edit plan for each video (timeline, captions, card pop-ups, Shorts)

Requires ffmpeg (with libass) and `pip install -r editor/requirements.txt`.
